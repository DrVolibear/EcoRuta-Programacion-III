ECORUTA FINAL
1. Abra la carpeta con Visual Studio Code.
2. Use Live Server para abrir index.html. No abra el HTML directamente con file:// porque datos.json se carga mediante fetch.
3. La aplicación conserva datos en localStorage bajo ecoruta_estado_v2.
4. En Configuración puede exportar/importar respaldos, cargar datos demo o restablecer.
5. Para probar paginación, cargue demo y registre al menos 6 envíos.
6. La impresión se ejecuta desde Ver detalles y oculta completamente el resto de la aplicación.
