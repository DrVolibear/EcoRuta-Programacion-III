ECORUTA v2.2.0
1. Abra la carpeta con Visual Studio Code.
2. Use Live Server para abrir index.html. No use file:// porque datos.json se carga mediante fetch.
3. La aplicación conserva datos en localStorage bajo ecoruta_estado_v5 y migra versiones anteriores.
4. En Configuración puede exportar/importar respaldos, cargar datos demo o restablecer.
5. La impresión se ejecuta desde Ver detalles y oculta el resto de la aplicación.
